# Homebrew tap for Furnace

```bash
brew install gilfeather/tap/furnace
furnace --model-name resnet18
```

[Furnace](https://github.com/Gilfeather/furnace) is an inference server for Burn and ONNX models
that speaks the KServe / Triton Open Inference Protocol. The formula installs the release binary
for macOS (Apple Silicon, Intel) or Linux (x86_64, ARM64) with the weights of its built-in
ResNet-18.

`Formula/furnace.rb` is generated by Furnace's release workflow on each release; change
`packaging/homebrew/furnace.rb.in` in the Furnace repository instead.
